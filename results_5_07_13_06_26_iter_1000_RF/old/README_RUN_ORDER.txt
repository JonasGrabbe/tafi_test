RUN ORDER
=========
A. Classification-report analysis

1. Put every results_tuning_* folder directly inside this project folder.
2. Run both dependent scripts with one command:
     Rscript run_classification_analysis.R

Or run them separately in this required order:
     Rscript consolidate_classification_reports.R
     Rscript accuracy_by_level.R

The accuracy script reads the CSV written by the consolidation script.

B. Automated skeletal workflow (separate branch)

This script does not read either CSV above. It requires the object `tb` from your existing
feature-building workflow. After `tb` exists in R, run:

  source("automated_skeletal_workflow.R")
  out <- run_all_experiments(tb)

Its results_skeletal_YYYYMMDD_HHMMSS folder is automatically created inside this project folder.

IMPORTANT
=========
Run the files with Rscript or source(). Do not execute only selected lines in RStudio, because
the automatic script-folder detection relies on the script being run/sourced as a file.
