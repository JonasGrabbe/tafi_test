Automated skeletal-representation metadata experiments

This report runs eight hypothesis-driven metadata experiments using the 63 selected skeletal-representation features.

For each experiment, the workflow saves group sizes, descriptives, assumption checks, Kruskal-Wallis tests, BH-FDR adjusted p-values, epsilon-squared effect sizes, Dunn post-hoc tests, PERMANOVA, PCA variance/loadings/scores, and three interactive Plotly plots.
