SITE-MEMBERSHIP EXPORT UPDATE

The original analysis stores numeric clusters separately within each feature space.
This update exports the exact site membership for every clustering solution.

C-labelled feature space: C + evenness
G-labelled feature space: NOT DEFINED - edit G_FEATURE_SPACE_FOR_LABELS if needed

Important:
Cluster aliases are zero-based only for easier C0/C1/... or G0/G1/... naming.
Raw cluster numbers are preserved in every file.
The script never creates an extra cluster merely to reach C5 or G5.
